# Background music

The game plays the first music file in this folder (`.mp3`, `.ogg`, `.wav` or `.flac`, first by name) on a loop. Put your track here to use it.

The track the project was built with is **not included in the GitHub repository**, because its creator and licence are not recorded (see `docs/SOURCES.md`). Without a file here, the game uses its generated harmony, drone and melody layers instead, so it still has music and nothing breaks.

The built `Common Ground.exe` in the repository does contain that track. Do not share the executable outside the team until the track's licence is sorted out, or rebuild it without the file.
